# TrainManagement
This project focuses on the design and implementation of a Train Consist Management System to demonstrate how Core Java and fundamental data structures are applied to solve real-world railway operations challenges.

## Use Case 1: Initialize Train and Display Consist Summary

- Initializes the Train Consist Management system

- Displays the application welcome banner

- Creates an empty train consist using ArrayList

- Shows the initial bogie count

- Displays the current train consist

- Indicates that the system is ready for operations

## Use Case 2: Add Passenger Bogies to Train

- Demonstrates management of passenger bogies using ArrayList

- Adds new bogies to the train

- Removes an existing bogie

- Checks if a specific bogie exists

- Displays the final passenger train consist
